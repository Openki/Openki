# i18n

The files in this folder are generated automatically.
On every startup with `meteor npm run dev` the file `en.json` (English) is created/overwritten by `extract-translations`, based on all `t(...)`, `i18n(...)` and `{i18n ...}}` that occur in the code.
All textes in `en.json` get translated by weblate into other languages. Those translation get exportet into this folder.
